# Internationalization (i18n)

Player-visible text must **never** be hardcoded in Portuguese in `presentation/` code. Use `tr("KEY")` and translation files in `locales/`.

## Current state

- `locales/pt_BR.po`, `locales/en.po`, template `locales/messages.pot`
- `presentation/shared/locale_keys.gd` — central key catalog (like i18n key files)
- `platform/locale_service.gd` — autoload `LocaleService`; persists choice in `user://locale.cfg`
- Settings panel: language `OptionButton` calls `LocaleService.set_locale()`
- Legacy PT strings still exist in some Labels and skill `.tres` fields — migrate gradually

## Godot configuration

In `project.godot` (when enabled):

```ini
[internationalization]
locale/translations=PackedStringArray("res://locales/pt_BR.po", "res://locales/en.po")
locale/fallback="pt_BR"
```

## `.po` format

```po
# locales/pt_BR.po
msgid "INVENTORY_TITLE"
msgstr "Inventário"

# locales/en.po
msgid "INVENTORY_TITLE"
msgstr "Inventory"
```

## Usage in GDScript

```gdscript
# presentation/inventory/inventory_menu.gd
label_title.text = tr("INVENTORY_TITLE")

# With parameter
tr("COMBAT_WORLD_UNLOCKED") % world_number
# COMBAT_WORLD_UNLOCKED = "Mundo %d liberado!" / "World %d unlocked!"
```

### Rules

1. **Keys** in `SCREAMING_SNAKE`, module prefix (`INV_`, `COMBAT_`, `TREE_`).
2. **Do not** concatenate translatable sentences — one key per complete message.
3. Plurals: separate keys or `%d` with fixed order.
4. Tooltips and buttons: same key if identical text; distinct keys if context differs.

## Where to apply `tr()`

| Layer | `tr()`? |
|-------|---------|
| `presentation/` | **Yes** — all visible text |
| `domains/` | No — return codes/keys; UI translates |
| `data/` Resources | Avoid; prefer key or `display_name_key` field |
| `CombatController.aviso` | Migrate to `toast_requested` + key |

## Dynamic content (items, skills)

Today `ItemData.nome` and `SkillResource.skill_name` are literal strings.

**Target:**

```gdscript
# ItemData
@export var name_key: String = ""  # "ITEM_SWORD_IRON"

func get_display_name() -> String:
	return tr(name_key) if name_key != "" else nome  # legacy fallback
```

## Icons and art

Sprites are not translated. Avoid embedded text in PNGs.

## Workflow for a new string

1. Add key in `locales/pt_BR.po` and `locales/en.po`.
2. Use `tr("KEY")` in UI.
3. Playtest with EN locale (Project Settings → Locale).
4. Do not leave orphan keys (grep the key in both `.po` files).

## Quick test

1. Switch locale to `en`.
2. Open inventory, skill tree, combat toasts.
3. Check Label overflow (English is often longer).

## AI / agents

When creating new UI:

- Never commit `label.text = "Inventário"` in `presentation/`.
- If `locales/` does not exist on the branch yet, create entries with the UI.
